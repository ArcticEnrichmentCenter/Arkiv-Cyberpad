Arkiv is a touch-based cyberdeck. The arkiv is intended to house a library of offline knowledge.

![DSCF3576](https://github.com/user-attachments/assets/6f79358f-5461-423c-92b0-4c6c4d88ddf7)


Arkiv has an internal buck-converter, so it can take a wide variety of voltage sources. Currently, two battery modules are developed, a rechargeable 2S 18650 module for everyday use, and a 10AA battery module for emergenciens when recharging is not possible.
<img width="1749" height="1236" alt="batt outline" src="https://github.com/user-attachments/assets/26098ae6-9e5a-4881-972c-3dd2cb1b7ad9" />
The batteries are housed in the grip, wich swings out at the pull of the battery release lever.

specs: 
screen: 10.1 in touchscreen
Compouting: rasberry pi 5
Battery: 2s 18650 or 10 AA.
This project is still in very early development. Current source files are published, more info to come.
